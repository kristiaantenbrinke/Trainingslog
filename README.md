# Trainingslog

Trainingsapp van Kristiaan en Rutger. Per oefening houden we per ronde de kilo's en herhalingen bij, met een korte notitie. Bij de volgende training staan de gewichten van de vorige keer automatisch klaar.

- `index.html`: de app
- `sw.js`, `manifest.webmanifest`, `icon-*.png`: zorgen dat de app vanaf het beginscherm opent en ook zonder bereik werkt
- `supabase-setup.sql`: de database in Supabase (eenmalig uitvoeren)
